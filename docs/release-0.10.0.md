# 0.10.0：在页边批注中插入本地图片

批注编辑框支持粘贴截图和选择 PNG、JPEG、WebP 文件。图片先保存在当前 PDF 同目录下的 `margin-comments-assets/<PDF 附件 Key>/`，再在光标位置插入 Markdown 相对引用；原图不会写进 PDF 或作为 Base64 写入评论。

## 行为

- 按图片内容 SHA-256 命名，重复内容复用同一文件；按文件真实格式选择扩展名。
- 阅读时按卡片宽度显示图片，编辑时保留可修改的引用并在下方显示缩略预览；点击图片放大，Esc 关闭预览。
- 图片加载后重新计算卡片高度和引线。开启折叠时图片使用缩略显示，低缩放时显示图片标记；关闭折叠后可查看完整内容。
- 图片存盘期间保留原编辑位置；取消编辑、关闭卡片或禁用插件后，不把迟到的引用插回正文。失败时不插入无效引用，原文和其他草稿保持。
- 删除图片引用或取消编辑不自动删除文件；此版本不提供自动清理。
- 仅加载当前 PDF 资源目录中的受控图片引用；任意本地绝对路径、跨目录引用和远程图片仍不加载。
- 修改 PDF 文件名不影响资源引用。移动 PDF 时需一起移动资源目录，目录不可写或 PDF 不在本机时提示原因。只读批注不能插图。
- 图片文件没有注册为 Zotero 附件，此版本不提供图片跨设备自动同步。备份和迁移需包含资源目录；无插件时原生评论显示引用文字。

## 验证入口

- `corepack pnpm test`：目录、去重、原子写入、引用限制、图片缺失、光标插入、异步取消、焦点、只读和文件选择入口。
- `corepack pnpm run typecheck`、`corepack pnpm run stress`。
- `corepack pnpm run build`、`corepack pnpm run verify:xpi`。
- `node scripts/verify-zotero-runtime.mjs "<zotero.exe>" "<测试 PDF>" --images --native-clipboard`：隐藏的独立 Zotero 测试窗口与独立数据库，检查实际图片剪贴板、磁盘文件、保存引用、原生撤销、取消、图片解码、PDF 重命名、会话重建、缺失恢复和点击放大。结果与截图位于 `build/zotero-images-qa/`。

该原生图片测试使用非无头模式，因为 Zotero 当前引擎的无头剪贴板不提供图片数据。测试始终使用独立文献库，结束时恢复测试前读取到的常见剪贴板格式。
