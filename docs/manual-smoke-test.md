# Zotero 9 / 10 人工验收

Zotero 10 的原生自动检查版本为 10.0.8；以下为完整人工验收清单，自动检查记录见各版本说明。

1. 使用单独的 Zotero 测试配置文件安装 `margin-comments-0.11.1.xpi`。
2. 打开包含高亮评论、下划线评论和独立便签的 PDF。
3. 确认工具栏出现“页边批注”按钮；明显位于页面左半区批注的卡片位于左边，右半区批注的卡片位于右边，引线从真实批注片段的上边缘引出。为单栏正文添加第一条居中长高亮或下划线评论，确认优先在右侧；继续添加时仍会使用两侧，右侧拥挤时新卡片使用左侧。评论文字的长短不影响判断。再在双栏正文分别添加评论，确认明确位于左右栏的批注保持就近选侧。编辑、缩放、筛选、隐藏再显示和新增评论不应使已有居中卡片换边；旋转后恢复方向应恢复原分配。
4. 在同一侧创建足以超过页面高度的评论，确认页面底部出现“还有 N 条”，且卡片不延伸到下一页。
5. 点击“还有 N 条”，确认只有当前侧边栏展开滚动；滚动时可见卡片的引线同步移动，滚出视野的卡片不显示引线；点击“收起评论”恢复折叠。
6. 确认卡片顶部不再显示“高亮解释/文本批注”和页码，只显示评论内容。
7. 鼠标悬停卡片，确认卡片轻微向外放大并出现浮起阴影，同时对应引线和 Zotero 原批注同步加重；移开鼠标后恢复。
8. 点击卡片，确认原批注被 Zotero 选中并定位；点击原批注，确认对应卡片边框高亮。
9. 在卡片输入中文，等待 700 ms；关闭再打开 PDF，确认内容仍在 Zotero 原批注中。
10. 确认卡片中没有“保存”按钮，并测试 `Ctrl + Enter` 立即保存、`Esc` 取消以及失焦保存。
11. 为评论输入四行以上内容，失焦后确认只预览三行且末尾有省略号；点击预览后确认完整编辑框展开。
12. 将 PDF 依次缩放至 50%、100%、200%，确认卡片、字号、图片、引线随页面等比缩放，文字换行、预览行数、相对位置与折叠状态不因缩放改变。
13. 对没有评论的高亮右键，选择“在页边显示/编辑评论”，输入内容并保存。
14. 新建一个 Zotero 独立便签，确认空卡片随即出现并可写详细内容。
15. 连续快速放大和缩小 PDF，确认卡片与引线逐帧跟随页面，不短暂串位、不消失、不闪烁；再测试旋转、窗口调整和翻页，确认引线仍指向正确位置。
16. 点击工具栏按钮隐藏和重新显示卡片；重启 Zotero 后确认开关状态保留。
17. 切换深色模式，确认卡片和文本框可读。
18. 测试只读组库批注，确认卡片显示“只读”且不可修改。
19. 禁用并重新启用插件，确认工具栏按钮、覆盖层和事件没有重复。
20. 分别打开“有旁注”和“无旁注”的 PDF，连续放大、缩小，确认两种情况的缩放中心都始终位于页面中线。
21. 在 Zotero 原生批注筛选中按颜色、标签或搜索词过滤，确认被过滤的批注及对应旁注同时隐藏；清除筛选后两者同时恢复。
22. 打开 Zotero“编辑 → 设置 → 页边批注”，依次取消高亮、下划线、便签、文字批注和图片/区域的勾选，确认对应类型立即隐藏；重新勾选后立即恢复。关闭并重新打开 Zotero，确认各类型的选择被保留，且 Reader 工具栏中不再出现设置齿轮。
23. 在“编辑 → 设置 → 页边批注 → 阅读器外观”中开启“缩小便签图标”，确认说明文字包含强版本依赖提示；所有已打开 PDF 的原生便签图标应立即从 24 像素缩小到约 14 像素，只能在缩小后的图标范围内选中和拖动，引线圆点落在图标上边缘；缩放、旋转后仍保持对齐。关闭后应立即恢复原始图标和点选范围，重启 Zotero 后选择仍被保留。
24. 关闭“自动折叠笔记”，确认长笔记显示完整内容；缩放至 80% 以下仍保持完整；密集评论自动使用页边栏滚动且不再显示“还有 N 条/收起评论”按钮。重新开启后恢复三行预览及密集评论折叠。所有已打开 PDF 应立即同步，重启后保留选择。
25. 在编辑中输入尚未保存的文本后切换“自动折叠笔记”，确认草稿、光标焦点仍保留；保存后重新打开 PDF，内容不丢失。
26. 输入 Markdown 标题、加粗、嵌套列表、引用、代码块和表格，失焦后确认按格式渲染；点击卡片后仍能编辑原文中的 Markdown 标记，保存、取消、关闭再打开均不丢失标记。已有 Zotero 粗体、斜体和上下标仍正常显示。
27. 用 Tab 聚焦卡片，按 Enter 或空格进入编辑；点击 Markdown 的 HTTPS 链接，确认由 Zotero 打开链接且不进入编辑。只读批注能查看 Markdown 但不可修改。任意 HTML/脚本按文本显示，远程图片仅显示说明文字。
28. 关闭折叠，打开高度超过 800px 的长笔记，在开头、中间、末尾分别进入编辑。确认编辑卡片不缩小为 156px 小框、正文不出现内部滚动条，保留进入编辑前的可视高度；继续输入时自然增长，删除内容时仍保留本次编辑空间。长内容通过页边栏滚动，进入编辑时不因聚焦而跳回开头。失焦保存、Esc 取消、重新进入编辑后内容与 Markdown 渲染正常。开启折叠后，长笔记编辑仍可完整展开。
29. 粘贴 README“数学公式”示例，确认相似度下标、精确率分式、上划线与乘号正常显示；再输入 `\(x_i^2\)` 和跨行 `\[...\]`，以及 `aligned` / `pmatrix` 环境，确认显示公式而非 LaTeX 原文。
30. 点击包含公式的卡片进入编辑，确认分隔符与反斜杠仍完整保留；修改后分别用失焦、700 ms 自动保存、Ctrl/Cmd+Enter 保存，关闭重开 PDF 后公式不丢失。Esc 取消草稿后恢复已保存的公式。
31. 关闭折叠，输入超过卡片宽度的独立公式和行内公式，确认可横向滚动到两端且卡片不撑宽、相邻卡片和引线不重叠；切换深色模式后公式颜色可读。重新开启折叠并缩放至 80% 以下，确认仍为一行预览且恢复缩放后公式结构正常。
32. 输入错误公式 `$$\frac{1}{$$`、未知命令以及未闭合分隔符，确认保留可编辑的原文，其他公式与 Markdown 继续显示。行内代码和代码块中的公式不渲染，`\$` 保留为美元符号；断网后公式仍可显示。
33. 输入 `$$\overline{\operatorname{sim}}$$`、`$$\hat{\operatorname{sim}}$$`、`$$\underline{\operatorname{sim}}$$` 和 `$$\frac{\operatorname{sim}}{\operatorname{cos}}$$`，确认横线、帽子位于函数名上方，下划线位于下方，分式上下排列；再检查 README 中的完整 Precision 公式、嵌套上下划线、行内公式和深色模式。点击编辑后 LaTeX 原文保持不变。
34. 首次打开没有批注的 PDF，画高亮并在 Zotero 原生批注中输入评论，等 Zotero 保存后确认页边卡片与引线出现，无需关闭 PDF。再给已有空高亮首次填写评论、修改评论、删除评论和新增独立便签，确认卡片同步更新；清除所有评论后额外页边栏消失。单纯高亮且无评论时不显示空卡片。
35. 隐藏页边批注期间新增或修改原生评论，再开启页边批注，确认显示最新内容；同时检查原生颜色、标签、搜索筛选及“显示批注”开关仍控制卡片显隐。在页边卡片编辑草稿时新增其他批注，确认草稿和焦点保留，结束编辑后新卡片自动出现。
36. 打开 PLLaVA 摘要页或有较大左右留白的论文，等待检测结束，确认卡片利用纸内留白贴近原文，引线终点连接卡片内侧；默认宽度为 360px，放不下的部分向纸外延伸。完全放得下时不预留固定的纸外旁注宽度。
37. 同页分别给较窄的摘要与较宽的正文添加评论；关闭折叠并输入长笔记，使卡片跨过两段内容，确认只调整位置，保留所设宽度，并按整张卡片所占高度内的最窄留白避开正文和图表。密集评论展开滚动后也不跨进原文。
38. 设置宽度为 360px，缩放 PDF 至 50%、100%、200%，确认屏幕卡片宽度分别约为 180、360、720px，且文字排版与相对布局一致；编辑、保存、失焦和只读批注均遵循相同缩放规则。
39. 连续缩放、旋转 90/180/270 度并恢复方向，确认卡片与引线跟随，缩放不重新扫描页面，切回已分析的方向可复用结果；没有评论的另一侧不保留空的批注列。
40. 首次打开 PDF 后立即编辑评论，在后台留白检测结束前输入草稿，确认文字、选区和焦点保持，结束编辑后正常应用检测结果。检测尚未结束时关闭 PDF 或禁用插件，确认没有残留卡片和后台绘制错误。
41. 用含图表、竖排 arXiv 字样、水印和扫描内容的页面检查候选留白；渲染未完成或失败时应回退纸外，页边太窄时保留宽度向外延伸，不根据高亮/引线/批注卡片自身误判原文范围。
42. 在“设置 → 页边批注 → 阅读器外观”用滑块或数字将“注释框宽度”改为 480px，确认两种控件同步、所有已打开 PDF 立即更新、重启后保留；PDF 50% 时卡片宽约 240px，100% 时约 480px。“恢复默认”将两个控件与实际宽度恢复到 360px 基准。输入草稿时改变宽度或缩放，确认文字、光标与焦点保持；空值和超出 200–640 的数值在提交时恢复默认或限制在有效范围。
43. 在笔记编辑框中输入九行中文，分别从上往下、从下往上拖选超过六行，并放慢到超过 700ms 自动保存间隔，确认选区始终在笔记内、原文不被改选；再把按住鼠标的指针移到卡片外并松开，确认不会启动正文选区。随后正常拖选 PDF 原文，再返回笔记拖选，两者均应可用。切换窗口、禁用插件、关闭 PDF 后重新打开，不能残留阻断正文操作的拖动状态。
44. 在文字中间粘贴截图，确认图片先存入 PDF 旁 `margin-comments-assets/<附件 Key>/`，引用插入原光标处且前后文字保留；等待保存，关闭重开 PDF，确认图片仍显示。重复粘贴相同截图时复用文件；使用 Ctrl/Cmd+Z 撤销引用、Esc 取消尚未保存的编辑后，当次不立即删除文件，下一次打开时无引用图片自动清理。
45. 点击“插入图片”选择 PNG、JPEG、WebP，确认编辑框保留引用，下方显示预览；取消文件选择不改变正文。用键盘 Tab 聚焦“插入图片”按钮时编辑框应保持展开。点击预览放大，Esc 只关闭图片预览。
46. 在插图保存期间取消编辑、隐藏旁注或关闭 PDF，确认迟到的结果不插回已关闭的编辑框；目录不可写和只读批注不能产生无效引用。暂时移走资源图片，确认显示缺失提示且原文保留；恢复后隐藏再显示卡片应重新加载。重命名同一 PDF 后引用仍可用；移动 PDF 时一并移动资源目录。
47. 插图后测试三行折叠、关闭折叠、长笔记滚动、Markdown/公式混排、深色模式、卡片宽度和缩放变化。低缩放时仍按比例显示图片，不切换成文字标记。图片加载后引线与卡片重新布局，图像保持等比，不撑出卡片或覆盖正文。普通文本粘贴、文本框选与复制继续可用，远程图片与任意本地路径不会被加载。
48. 两条批注共用同一图片，删除一处引用并重开 PDF，确认文件仍在；删除最后一处引用并保存，再次打开后文件应被删除。被类型、颜色或页面筛选隐藏的引用仍应保留图片。取消插图留下的无引用文件应在后续打开时清理。只在当前 PDF 专用目录中清理，保留自定义文件、临时文件、子目录、符号链接和其他附件资源。输入、缩放、刷新及旁注显隐切换不能反复触发清理；同一 PDF 的另一窗口正在编辑、插图或有未保存草稿时应跳过本次检查。
49. 在“设置 → 页边批注 → 阅读器外观”用滑块或数字调整“批注字号”，确认范围 8–32px、步长 0.5px，两个控件同步，12.5px 默认值可恢复。设为 18.5px 后，所有已打开 PDF 的预览与编辑文字立即更新，Markdown 标题和公式相应调整，卡片高度与引线重新定位且不重叠；重启后保留字号。PDF 50%、100%、200% 时字号按比例显示，换行与相对布局保持稳定。编辑草稿时修改字号仍保留文字、光标与选区；逐字输入 18.5 时小数点不被重置，空值或超出范围在提交后恢复默认或限制在范围内。
