# 0.9.0：利用页边留白，保留阅读宽度

批注利用论文自身的左右留白靠近正文，卡片保持所设宽度，空间不足的部分可以超出纸张边缘。

## 行为

- 根据无批注 PDF 渲染的非白色像素与文字边界建立页面留白分布，不从屏幕截图或带高亮的阅读器画布取样。
- 同一侧保持统一列位置；按实际显示卡片的整个高度核对正文边界。密集评论滚动时改用整页连续留白。
- 卡片默认宽 360 CSS px，在“设置 → 页边批注 → 阅读器外观”可调整为 200–640px，持久保存并立即应用到已打开的 PDF。
- 留白只决定卡片位置：靠原文一侧保留 10px 间距，另一侧可以向纸外延伸；缩放 PDF、进入和结束编辑时不因留白变窄而压缩卡片或切换成笔形入口。表格与长公式仍可内部横向滚动。
- 渲染未就绪或检测失败时沿用纸外布局，同样保留所设完整宽度。只读批注使用同一宽度规则。
- 检测结果按页面和旋转方向缓存，缩放复用结果。每次仅分析一页，关闭阅读器时取消正在执行的分析。
- 仅按实际超出纸面的部分预留纸外空间；引线直接连接当前卡片边缘，悬停与选中不会放大卡片压住原文。
- 保留 0.8.12 的批注实时更新、Markdown / LaTeX、编辑草稿保护、筛选和自动保存。

## 验证

- 自动测试：`corepack pnpm test`。
- 类型检查：`corepack pnpm typecheck`。
- 密集批注：`corepack pnpm stress`，覆盖 50 / 150 / 300 / 600 / 1000 条。
- 真实 PLLaVA PDF + Chromium：`node scripts/verify-whitespace-browser.mjs "<PLLaVA PDF 完整路径>"`。使用独立无头浏览器配置目录，不控制用户的 Zotero。
- 浏览器场景覆盖 200% 表格与公式、100% 跨纸边完整宽度、长笔记编辑、50% 下保持宽度、480px 自定义宽度、旋转 90 度和恢复方向；逐场景检查卡片与纸面相交的区域是否覆盖原文非白色像素，同时核对缩放缓存与纸外空间。
- 浏览器结果和截图位于 `build/whitespace-browser-qa/results.json` 与 `screenshot.png`；临时浏览器与本地验证服务器在脚本结束时关闭。
- 构建与 XPI 检查：`corepack pnpm build`、`corepack pnpm verify:xpi`。

这些检查不等于已在运行中的 Zotero 完成人工验收；安装后检查见 [manual-smoke-test.md](./manual-smoke-test.md)。复杂扫描件、水印、PDF 字体或渲染兼容性仍可能使检测回退到纸外。

## Zotero 跨窗口兼容修复

首个 0.9.0 包在真实 Zotero 中可能始终显示纸外卡片：插件作用域创建的 PDF.js 参数跨入内容窗口后，计算的页面宽度为 `NaN`，留白分析失败并回退。通用浏览器验证未覆盖这个 Gecko 权限边界。

修正版把渲染参数、Canvas 与 PDF.js 调用放到 PDF 窗口自身执行，只返回 JSON 文本；关闭时也在同一窗口取消渲染。失败结果不再永久缓存，页面重绘时可以重试。原有缩放缓存与串行分析继续保留。

新增 `node scripts/verify-zotero-runtime.mjs "<zotero.exe 完整路径>" "<PLLaVA PDF 完整路径>"`：启动独立配置与独立数据库，复制 PDF 并建立测试批注，在 Zotero 原生 Reader 中检查卡片利用纸内留白并向纸外延伸、表格与公式渲染。不会连接用户已运行的 Zotero，也不使用用户数据库。结果位于 `build/zotero-runtime-qa/results.json`，实际界面截图位于同目录 `screenshot.png`。

已在本机 Zotero 10.0.8 原生进程中复现旧调用得到 `NaN`，修复后得到 297 段留白数据；当前宽度优先版本的原生卡片模式为 `overhang`，宽度保持 360px，靠正文一侧在纸内，另一侧超出纸边，Markdown 表格与 MathML 均存在。另通过 69 项自动测试、类型检查和浏览器场景验证。这是独立配置的自动验收，用户日常配置中的人工验收仍需安装更新包后确认。

## 笔记跨行拖选修复

Zotero 在 PDF 窗口捕获阶段处理鼠标按下，会穿过覆盖层命中下面的纸张并启动 `selectText`。原先仅在编辑框阻止冒泡，无法阻止这个更早执行的处理，拖选笔记时可能转为选择 PDF 正文。

现在通过原生指针处理的提前返回入口隔离笔记卡片；从编辑框开始的手势会持续归编辑框处理，直至松开鼠标、取消或窗口失焦。保留浏览器原生文本选区，不阻止默认拖选。桌面默认选择钩子的清除和文字层拖动行为保持原有逻辑，插件关闭时恢复钩子并移除监听器。

新增 `node scripts/verify-zotero-runtime.mjs "<zotero.exe>" "<PLLaVA PDF>" --drag`，在独立 Zotero 10.0.8 中使用可信鼠标事件验证。旧版复现为 PDF `selectText`、选区落在正文；修复后向下跨六行选中 144 个笔记字符、反向拖选 190 个字符，选区两端均在编辑框内，PDF 选区为空。慢速拖动覆盖自动保存间隔，松开后 PDF 正文选取恢复正常。自动测试共 73 项通过，类型检查通过。
