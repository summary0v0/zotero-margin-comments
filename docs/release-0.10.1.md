# 0.10.1：打开 PDF 时清理未引用图片

删除批注中的图片引用后，当次编辑仍可撤销；下一次打开 PDF 时，自动检查并删除不再被该 PDF 任何现存批注引用的插件图片。

## 清理规则

- 每个 PDF 阅读会话初始化时请求一次检查，刷新、输入、缩放、类型筛选和隐藏再显示不会重复清理。
- 直接读取 PDF 的全部现存批注正文，包含其他页面、未显示类型和隐藏批注；数据未就绪或读取失败时停止清理，不把失败当作零引用。
- 同一张图片只要还有一处引用就保留；每次删除前重新读取引用。普通文字、代码示例和部分 Markdown 中的图片路径也按引用保留。
- 仅枚举 `margin-comments-assets/<当前附件 Key>/` 的直接子文件，只删除插件生成的 `<SHA-256>.png/.jpg/.webp` 文件；不递归、不删除目录，不触碰普通文件、临时文件、符号链接或其他 PDF 的资源。
- 同一 PDF 的多个窗口共享编辑/插图保护。存在编辑、未保存草稿或正在写图时本次跳过，下一次打开再检查。若删除已在执行，新插图会先等待该删除完成，再存图或复用文件。
- 只读附件或资源目录为符号链接时跳过。关闭阅读器后停止后续删除；清理失败不会阻止正文和旁注显示。

清理以当前 PDF 的批注引用为准，不扫描外部 Markdown 文件和其他应用的笔记。图片仍保存在本机，跨设备自动同步不在本版范围。

## 验证入口

- `corepack pnpm test`：引用完整性、共享引用、删除前复核、只读/编辑保护、目录范围和并发插图。
- `corepack pnpm run typecheck`、`corepack pnpm run stress`。
- `corepack pnpm run build`、`corepack pnpm run verify:xpi`。
- `node scripts/verify-zotero-runtime.mjs "<zotero.exe>" "<测试 PDF>" --images --native-clipboard`：使用独立 Zotero 配置和数据库创建未引用图片，验证重开后删除、引用图片保留、无关文件保留以及显隐切换不重复清理；同时回归粘贴与图片重载。

安装包：`releases/margin-comments-0.10.1.xpi`。覆盖安装后重新打开 PDF。
