## 为什么需要它？

Zotero 默认将高亮、下划线等批注的评论集中显示在 Reader 侧栏中。阅读正文时，批注位置与解释内容彼此分离，需要反复移动视线。

Margin Comments 优先将评论卡片放进 PDF 白色纸张内部的左右页边留白，并用短引线连接原批注：

```text
PDF 原批注  ─────  引线  ─────  页边评论卡片
     ↑                              │
     └──────── 自动保存回 Zotero ────┘
```

插件直接使用 Zotero 原有批注数据，不修改 PDF 文件，也不建立另一套批注数据库。

## 设置

打开 **Zotero → 编辑 → 设置 → 页边批注**：

- 选择需要显示的批注类型：高亮、下划线、便签、文字、图片与区域。
- 设置 **注释框宽度**：用滑块或数字调整 PDF 100% 时的宽度，默认 360px，范围 200–640px，支持“恢复默认”。修改后自动保存并立即应用到所有已打开的 PDF；随后随页面等比缩放。
- 设置 **批注字号**：默认 12.5px，范围 8–32px，步长 0.5px，支持滑块、数字输入和“恢复默认”。预览和编辑文字立即更新，修改后自动保存并应用到所有已打开的 PDF；缩放 PDF 时按比例显示。
- 开启或关闭 **自动折叠笔记**，控制三行预览和密集评论收起。默认开启；关闭后显示完整内容。缩放不会切换预览行数或重新换行。
- 笔记阅读状态自动渲染 Markdown：标题、加粗、斜体、列表、引用、代码、链接和表格；点击卡片编辑原文，保留 Markdown 标记。
- 自动渲染 LaTeX 数学公式：行内 `$…$` / `\(...\)`，独立公式 `$$…$$` / `\[...\]`；支持分式、上下标、求和、矩阵和多行对齐，长公式可横向滚动。点击编辑、保存时仍保留公式原文。
- 开启或关闭 **缩小便签图标**，将 PDF 页面原生便签图标缩小到 14px。
- 设置会持久保存，并立即应用到所有已打开的 PDF。

> [!WARNING]
> “缩小便签图标”依赖 Zotero Reader 的内部 Canvas 实现。若 Zotero 更新后出现图标、点选范围或引线异常，请先关闭该选项。

## 安装

1. 下载 [最新版 `margin-comments-0.11.1.xpi`](./releases/margin-comments-0.11.1.xpi?raw=1)。
2. 打开 **Zotero → 工具 → 插件**。
3. 点击右上角齿轮，选择 **从文件安装插件**。
4. 选择下载的 `.xpi` 文件，并按 Zotero 提示完成安装。

首次试用建议使用单独的 Zotero 测试配置文件。历史安装包保存在 [`releases/`](./releases/) 目录中，可以随时回退。

0.11.1 新增批注字号设置，支持 8–32px、0.5px 步长、即时应用、自动保存与恢复默认，并继续随 PDF 等比缩放。见 [0.11.1 更新说明](./docs/release-0.11.1.md)。

0.11.0 改为卡片与 PDF 等比缩放，保持相对布局、换行和预览行数；新增注释框宽度滑块、数字输入和恢复默认。详见 [0.11.0 更新说明](./docs/release-0.11.0.md)。

0.10.1 新增打开 PDF 时的图片清理：一张图片不再被该 PDF 的任何现存批注引用时，在下一次打开 PDF 时删除；同一图片的多处引用、正在编辑或保存中的图片受到保护。清理不会随输入、缩放、筛选或旁注显隐反复执行。见 [0.10.1 更新说明](./docs/release-0.10.1.md)。

0.10.0 新增批注插图：粘贴截图或选择本地图片，图片保存在 PDF 旁，批注保存可编辑的 Markdown 相对引用。图片支持预览、点击放大和缺失提示，保留 0.9.2 的选侧规则。图片目录需要单独备份和迁移，当前不提供跨设备图片自动同步。见 [0.10.0 更新说明](./docs/release-0.10.0.md)。

0.9.2 在就近选侧规则之后加入长划线的右侧偏好：居中长高亮或下划线在两侧卡片数相同时先放右侧，右侧更拥挤时使用左侧；已分配卡片继续保持原侧。长划线的原文整体宽度阈值调整为页面宽度的 30%，规则与验证见 [0.9.2 更新说明](./docs/release-0.9.2.md)。

0.9.1 修复整行、跨行高亮容易集中在右侧的问题：明显靠近一侧的批注仍就近显示，仅对居中且较宽的文字选区使用两侧分配，已有卡片不因新增或编辑评论而换边。跨行高亮的引线从所选侧真实高亮片段的上边缘引出。规则与验证见 [0.9.1 更新说明](./docs/release-0.9.1.md)。

0.9.0 新增页边留白定位：独立读取无批注的页面渲染与文字边界，利用原文旁的空白区域靠近正文。卡片保持所设阅读宽度，允许向纸外延伸；位置和引线随缩放、旋转与内容高度调整。首次检测完成前可能暂时显示在纸外。检测在本机完成，不上传论文、不修改 PDF；复杂扫描件、水印或渲染失败时可能回退纸外显示。

0.9.0 修正版解决了 Zotero 跨窗口传参导致页面尺寸无效、旁注始终回退纸外的问题；已增加原生 Zotero 10.0.8 独立配置验证。若安装了较早的 0.9.0，请重新下载本目录中的安装包覆盖安装并重新打开 PDF。

当前 0.9.0 同时修复了编辑笔记时跨行拖选被 PDF 正文接管的问题。笔记内起始的拖选会持续留在笔记中，松开后仍可正常选取原文；已在原生 Zotero 中验证正向、反向跨行拖选及慢速拖动。

0.8.12 修复了首次填写批注评论后，页边卡片可能被旧的原生批注显隐状态隐藏、需要重新打开 PDF 才显示的问题。评论保存后会重新读取数据与当前显隐状态；批注变化和重新开启页边批注时也会同步刷新，无需关闭 PDF。纯高亮且未填写评论时仍不自动显示空卡片，可通过批注右键菜单“在页边显示/编辑评论”创建。

## 使用方法

1. 打开包含批注的 PDF。
2. 点击 Reader 工具栏中的 **页边批注** 按钮显示或隐藏卡片。
3. 点击卡片内容开始编辑；保存由插件自动完成。
4. 对尚无评论的批注点击右键，选择 **在页边显示/编辑评论**。

| 操作 | 效果 |
| --- | --- |
| 点击评论卡片 | 选中原批注并进入编辑 |
| 停止输入 700 ms | 自动保存 |
| `Ctrl/Cmd + Enter` | 立即保存 |
| `Esc` | 取消尚未保存的编辑 |
| 点击工具栏按钮 | 显示或隐藏全部页边批注 |

### 在批注中插入图片

1. 点击页边卡片进入编辑，在光标位置按 `Ctrl/Cmd + V` 粘贴截图；也可以点击编辑框下方的“插入图片”选择 PNG、JPEG、WebP 文件。
2. 图片成功保存后插入相对引用，继续沿用停止输入 700 ms、失焦或 `Ctrl/Cmd + Enter` 自动保存。图片无法保存时提示原因并保留正在编辑的文字。
3. 编辑框保留 Markdown 引用，下方显示图片预览；阅读状态直接显示图片，点击图片可放大，按 `Esc` 或点击关闭按钮退出预览。

文件布局示例：

```text
PDF 所在目录/
├─ 论文.pdf
└─ margin-comments-assets/
   └─ ABCD1234/             # 对应 PDF 附件 Key，重命名 PDF 不影响引用
      └─ <图片内容的 SHA-256>.png
```

批注中的引用形式为 `![说明](margin-comments-assets/ABCD1234/<图片指纹>.png)`。重复插入相同内容会复用文件。删除引用或取消插图时不立即删除磁盘图片，便于当次编辑撤销；下一次打开 PDF 时检查所有现存批注，无任何引用的图片会自动删除。

检查按该 PDF 的批注正文统计引用，包括未显示的类型、其他页面和被筛选隐藏的批注；即使引用只是写在代码或普通文字中，也会保留对应图片。只清理 `margin-comments-assets/<当前 PDF 附件 Key>/` 中符合插件命名规则的图片文件，保留其他附件目录、普通文件、临时文件、子目录和符号链接。若同一 PDF 正在其他窗口编辑、插图或有未保存草稿，本次跳过，等下次打开再检查。无法完整读取批注、只读或清理目录异常时不删除图片。

移动、备份 PDF 时请一起保留对应资源目录。当前版本按本机使用设计，图片文件没有注册为 Zotero 附件，不能把批注文字同步视为图片同步；原生批注面板和未安装插件的设备主要看到引用文字。远程图片链接不会自动下载。图片缺失时保留引用并显示提示，恢复文件后隐藏再显示卡片即可重新加载。

### 数学公式

在批注评论中直接输入 LaTeX，保存或失焦后自动渲染。例如：

```markdown
相似度为 $M_{ij}=\operatorname{sim}(s_i,g_j)$。

$$
P=\frac{N_{\text{matched-pred}}}{N_{\text{pred}}}
\cdot\overline{\operatorname{sim}}\cdot L_f
$$
```

- `\(...\)` 与 `\[...\]` 分别也可用于行内、独立公式。独立公式可以跨多行，建议分隔符单独占行。
- 代码块和行内代码中的公式保持原文；普通美元价格可用 `\$` 明确转义。
- 公式语法错误或命令不受支持时保留原文，其他内容继续正常显示。
- KaTeX 随插件离线打包，输出由 Reader 原生显示的 MathML，无需联网或额外下载字体。公式命令支持范围见 [KaTeX 文档](https://katex.org/docs/supported)。

0.8.11 修复了 `\overline{\operatorname{sim}}` 的横线被排到字母右侧的问题，同时处理帽子、下划线和分式中同类的函数名分组错误。已有笔记的公式原文无需修改。

## 开发与构建

需要 Node.js、Corepack 和 pnpm：

```powershell
corepack pnpm install
corepack pnpm run typecheck
corepack pnpm test
corepack pnpm run stress
corepack pnpm run build
corepack pnpm run verify:xpi
```

构建结果位于 `build/margin-comments-0.10.1.xpi`，同时会归档到 `releases/`。构建脚本不会删除历史版本。

## 项目结构

```text
addon/        Zotero 清单、设置页与静态资源
src/core/     批注模型与页边布局算法
src/zotero/   Reader 适配、会话、编辑器与数据存储
tests/        单元测试和 Reader 回归测试
bench/        密集批注压力测试
releases/     带版本号的历史 XPI
```

## 数据与隐私

- 不修改 PDF 文件。
- 不创建外部批注数据库。
- 评论仍保存在原来的 Zotero 批注中。
- 插件本身不需要网络服务或 API 密钥。
